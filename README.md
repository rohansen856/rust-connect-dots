"# Connect 4 - Multiplayer Edition

A Rust implementation of Connect 4 with local and network multiplayer support.

## Features
- Local multiplayer (same device)
- Network multiplayer (host/join games)
- Real-time synchronization over TCP

## Usage
```bash
cargo run
```

Choose from:
1. **Local Multiplayer** - Two players on same device
2. **Host Network Game** - Host on port 8080 (default)
3. **Join Network Game** - Connect to host (e.g., 127.0.0.1:8080)"
